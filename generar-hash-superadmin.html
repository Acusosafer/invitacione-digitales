Elegí una clave larga y difícil de adivinar. Usá al menos 16 caracteres, o tres o cuatro palabras sueltas que solo vos asocies. Esta clave abre TODOS los eventos, no uno.
  1. Copiá el SQL de arriba con el botón.
  2. Entrá a Supabase → SQL Editor → pegalo → Run.
  3. Tiene que decir Success. Si dice 0 rows, avisá: la fila no está y la clave no cambió.
  4. Probá entrar al panel con la clave nueva antes de cerrar esta pestaña. Si algo salió mal, todavía la tenés escrita acá.
Por qué se copia el hash y no la clave. Podrías hacer que Postgres calcule el hash solo, pero entonces tu clave en texto plano queda guardada en el historial de consultas del panel de Supabase. Así, la clave no sale nunca de esta pantalla: lo que viaja es el hash, que no se puede revertir.
